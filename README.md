# Nutrition Log

A Python application designed to help users calculate their daily nutritional needs and eventually track their nutrition and meals.

## Current Features

* Calculates Body Mass Index (BMI)
* Calculates Basal Metabolic Rate (BMR)
* Calculates Total Daily Energy Expenditure (TDEE)
* Calculates a suggested daily calorie intake based on the user's goal weight
* Validates user input for age, sex, height, weight, activity level, and goal weight
* Uses object-oriented programming with a `Person` class

## How It Works

The program asks the user for:

* Age
* Sex
* Height
* Current weight
* Activity level
* Goal weight

It then calculates:

* BMI
* BMR
* TDEE
* Suggested daily calorie intake
